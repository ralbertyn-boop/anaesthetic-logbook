# Anaesthetic Logbook

An offline, installable (PWA) anaesthetic case logbook structured to the Royal College of Anaesthetists' recommended **Logbook Summary Data Set** (2021 curriculum).

**Open the app:** https://ralbertyn-boop.github.io/anaesthetic-logbook/

- Log cases: specialty, age, ASA (+E), priority, actual level of supervision, primary mode, regional techniques, additional procedures, incidents and notes
- Log POM, acute pain and chronic pain sessions
- ARCP summary tables in the RCoA layout for any date range
- CSV export, JSON backup and restore
- Works offline once installed; all data stays on your device. Nothing is sent to a server.

## Install
- **iPhone/iPad:** open the link in Safari → Share → *Add to Home Screen*
- **Android:** open in Chrome → ⋮ → *Install app*
- **Desktop:** Chrome/Edge install icon in the address bar

## Notes
Independent tool, not an RCoA product. Record anonymised case details only. Back up regularly: deleting the app or clearing site data erases your entries.

When changing files, bump `VERSION` in `sw.js` so installed copies pick up the update.
